# Rhyan Orosco — Portfolio

React + Vite + Tailwind CSS v4 + Lucide React + React Router.

## Requirements
- Node.js 20.19 or newer (check with `node -v`)

## Run locally
```
npm install
npm run dev
```
Then open the URL shown in the terminal (usually http://localhost:5173).

## Build
```
npm run build
npm run preview
```

## Where things go
- `src/data/` — all text content (edit here to update the site)
- `src/assets/` — screenshots, diagrams, certificates, profile photo
- `src/components/` — reusable UI pieces
- `src/sections/` — page sections (Home page and `project/` case study)
- `src/pages/` — routes
- `src/hooks/` — small reusable hooks
